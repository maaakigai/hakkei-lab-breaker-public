# 開発プロセスと生成AIの利用

## 開発体制

本作品は、共同制作者2名が開発責任を持ち、CodexとClaudeを生成AIエージェントとして利用して制作しました。

人間2名が共同で担当した内容は次のとおりです。

- 課題設定と初期案の検討
- AI案の採用、修正、棄却
- AIへの追加指示
- 実行結果と実機動作の確認
- 受入判断とリリース判断
- 展示準備、当日運用、障害監視

生成AIエージェントは、マイルストーン案に加え、TypeScript、Python、旧Unity開発期のC#を含むコード、テスト、文書を直接生成・修正しました。基本の流れは、Codexがマイルストーン案を作成し、Claudeが修正した後、CodexとClaudeへ段階的に実装を依頼する形でした。生成された内容を無条件に採用せず、人間2名が処理経過、差分、実行結果、実機動作を観察し、共同で採用・修正・棄却、追加指示、統合、検証を行いました。

この文書はコード・テスト・文書作成におけるCodexとClaudeの利用を扱います。Wan2.2 I2V、GeminiによるCritical映像、画像生成支援を使ったUI素材の出典・権利整理は[`../ASSET_LICENSES.md`](../ASSET_LICENSES.md)を参照してください。ゲーム背景には、撮影者の同意を得た元の研究室写真を使用しています。

## 基本的な進め方

1. 人間2名が初期案と解決すべき課題を共同で定める。
2. Codexにマイルストーン案を作成させ、Claudeによる修正と再検討を行う。
3. CodexとClaudeへ段階的に実装を依頼する。
4. 人間が処理経過、変更内容、テスト結果、実機動作を確認する。
5. 問題があれば、案を棄却または修正して追加指示を出す。
6. 人間2名が受入、リリース、展示運用を共同で判断する。

## AI出力の受入と検証

確認方法は変更内容に応じて選びました。ロジックや通信処理ではコード差分、ログ、自動テストを確認し、UI、演出、ゲーム進行では人間2名が実際に操作・プレイして目視確認しました。mocopiやスマートフォンを使う経路は、可能な段階で実機を接続して確認しました。

実機確認では2名が互いにプレイし、意図した体験になっているか、既存機能へ問題を生じさせていないかを確認しました。問題があった場合は仕様を見直して追加指示を出し、意図しない機能や別の問題を発生させる変更は棄却しました。修正後に再確認し、人間2名が受け入れ可能と判断した変更だけを統合しました。すべてのAI生成コードを同一の方法で確認した、または全行を人間が手入力し直したという意味ではありません。

## 人間による設計変更の例

### 通信方式

QR登録後のスマートフォンと展示機の同期は、当初RESTポーリング中心で実装していました。maaakigaiは画面遷移時に不安定になる可能性を懸念し、実機確認でも不安定な挙動を観測しました。

そこで、maaakigaiがWebSocketによるサーバープッシュ優先方式への変更を提案し、AIエージェントへ再実装を指示しました。REST APIは初期同期と通信障害時のフォールバックとして維持しています。AIによる再実装後は人間2名が共同で受入確認を行い、その後の実機確認と1時間の展示では同じ問題は観測されませんでした。

技術的な変更記録は[`archive/development-runs/feature-development/20260709-websocket-session-sync.md`](archive/development-runs/feature-development/20260709-websocket-session-sync.md)に残しています。

### スマートフォンUI

AIによる初期案では、スマートフォン画面に同じ視覚的優先度のボタンが多数並び、文字を読まなければ次に押すべき操作を判断しにくい構成でした。また、画面遷移に伴ってメイン画面へ操作ボタンを追加する方式は、情報量が増えて誤操作の原因になる可能性がありました。

maaakigaiは展示中の短時間利用を想定し、使用頻度の低い操作を`OPTION`へ集約して不要な要素を削除しました。追加操作はメイン画面へ常時表示せず、階層化したダイアログ内で必要な場面にだけ表示する構成へ変更しました。これにより、主要導線では次に必要な操作が常に最も目立ち、参加者が目立つ主要ボタンを順に操作するだけで体験を進められるようにしました。結果画面とUI全体は2名が同程度に共同制作しており、この例はその中でmaaakigaiが主導した具体的な設計判断です。

## 素材制作での役割

- 通常Lv映像は`Wan-AI/Wan2.2-I2V-A14B`を使ったI2Vで制作し、attack114514が生成操作、プロンプト、シード値の設定を主に担当しました。
- Wan生成出力の採用・棄却は、人間2名が共同で判断しました。
- Critical専用の大型電波塔映像にはGeminiを使用しました。
- 動画・音響素材のゲーム内配置、展示用SFXの切り出し、ループ、再生タイミングの調整は、maaakigaiが主に担当しました。
- 公開版で配布する音声はすべて無音です。
