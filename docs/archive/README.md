# アーカイブ

このフォルダは、現在の公開版では使わない仕様、実験、レビュー、削除済み機能の実装記録を保管します。現行の起動・操作・要件・検証には使いません。

> 過去の記録にあるClaudeやCodexの役割名は、その時点のAIエージェント間の作業分担を示します。プロジェクト全体の課題設定、AI出力の採否、追加指示、受入・リリース判断は人間2名が共同で担当しました。現在の説明は[`DEVELOPMENT_PROCESS.md`](../DEVELOPMENT_PROCESS.md)を参照してください。過去の生ログ本文は履歴として保持しています。

- `legacy/`: Unity BridgeやCalibrationを前提にしていた旧仕様・旧要件・旧チェックリスト
- `experiments/`: 完了済みの実機実験計画と手順
- `development-runs/`: 現行実装へ至る過去の変更記録（時期・目的別）
- `design-history/`: 採用前の設計案と比較資料
- `internal-guidance/`: 開発時に使用したAIエージェント向け作業規律
- `removed-features/`: 公開版から削除した機能の変更記録
- `presentations/`: 過去の発表原稿
- `reviews/`: 解決済みレビュー
- `autostart-experiment/`: 採用しなかった起動方式の試作

削除済み機能の記録に出てくるファイル名や設定名は、現在のソース・設定・配布物には存在しません。
アーカイブ内の文書は当時の記録を保つため、古い相対リンクや開発時の表現をそのまま含む場合があります。
