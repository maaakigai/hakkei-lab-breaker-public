# 公開ポートフォリオ再構成

- 対象: 権利整理後の新しい公開リポジトリ作成準備
- 公開先: `maaakigai/hakkei-lab-breaker-public`

## 採用した判断

- 権利確認できない素材を含んでいた旧GitHubオブジェクトと履歴を引き継がず、新しいリポジトリへ公開する。
- 現行の操作・仕様・技術ノートを`docs/`直下へ残し、旧作業日誌、実装記録、設計ドラフト、AI向け資料は`docs/archive/`へ集約する。
- 約400倍の信号分離を確認したBLE実測だけは、採用担当が読みやすい技術ノートへ要約する。
- 削除済みの接待モード確認項目は現行チェックリストから外し、削除済み機能の記録へ移す。

## 理由

現在の作品と起動方法を初見で追いやすくしながら、実装判断の履歴は削除せず参照可能にするためです。また、新規リポジトリへ分離することで、通常のcloneやGitHub履歴から旧権利素材へ到達しない公開状態にします。
