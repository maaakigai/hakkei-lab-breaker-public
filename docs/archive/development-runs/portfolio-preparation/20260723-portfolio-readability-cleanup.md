## 採用した判断と理由

- 開発元リポジトリは非公開のため、閲覧できないリンクをREADMEへ掲載しない。
- 登録画面の画像は、実運用URL、読み取り可能なQRコード、セッションID、入力名を含むため掲載しない。
- 元動画にも同じ情報が映っていたため、その区間を除外し、1280×720へ圧縮して再現デモとして掲載する。
- 動画は実展示の記録と誤認されないよう、キーボード予備入力による再現であることを明記する。
- GitHubのモバイル表示ではMermaid図に大きな余白が生じたため、構成図を短い経路表へ置き換える。
- `SPEC.md`、`MILESTONES.md`、手動確認ガイド、エージェント指示は参照が多いためルート配置を維持する。
- Git履歴の大容量ファイル削除はforce-pushを伴うため、通常の可読性整理とは分離する。
