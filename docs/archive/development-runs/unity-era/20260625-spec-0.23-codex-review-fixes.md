# 2026-06-25 SPEC §0.23（単手回帰＋隠しイベント）codex レビュー反映

## 経緯
両手同期パンチは「爽快感が無い」とのユーザ指摘で撤回。通常プレイを利き手1本の単手に戻し、
「前方でない突き(下/上/後ろ)・両手特殊モーション・何もしない(idle)」を隠しイベント(イースターエッグ)に
する方針へ転換。SPEC.md に権威セクション §0.23 を追加した上で、codex に方針レビューを依頼
（開発時のローカルレビュー記録）。判定は **GO with required SPEC fixes**。

## 反映した codex 指摘（Required 4 ＋ Important）
- **Required 1（idle/timeout 矛盾）**: `hakkeiReadyTimeoutMs=5000` のまま `idleEventMs=15000` だと 15s idle が
  永遠に発火不能。→ 0.23.4 で `HakkeiReady` 終了＝`min(行動検出, idleEventMs, 手動キャンセル)`、不変条件
  `hakkeiReadyTimeoutMs >= idleEventMs + grace`、idle 計測は `HakkeiReady` 開始(detector reset 後)からのみ、と明記。
- **Required 2（非前方フォールバック）**: 「隠し未満は全部通常破壊」を撤回。0.23.6 に `resolveTrigger` の評価順序を明文化
  （強さ未満=noImpact → forward → hidden成立 → 非前方だがゲート不足=hiddenMiss(通常破壊にしない) → 谷間=noImpact）。
  例外救済は「forwardCos を僅かに下回る前方寄り」に限定。
- **Required 3（利き手決定）**: 0.23.2 を `DominantHandCheck` ステップ化。突いて選ぶ／短window で左右の
  net distance・speed peak を比較し `dominantHandMargin` 超の手を採用／同程度は「もう一度片手だけ」リトライ／
  R・UI で再選択／Keyboard 既定 right・デバッグキーで left。
- **Required 4（supersede ポインタ）**: §0.23 冒頭に supersede 対象章を列挙（§0.8/§9/§16/§18.3/§19）。
  §0.8・§9・§16・§18・§19 の各章冒頭に §0.23 優先ポインタを追加。段取り（今回 commit→次の実装前に旧表最小更新）も明記。
- **Important（真後ろ）**: 0.23.8。Phase A の手位置だけでは「振り向き」を厳密検出できないため `back` を
  「後方突き/背面方向イベント」に寄せ、厳密化は Phase B(skeleton/bodyForward) 後。UI と HUMAN_TEST_GUIDE_JA.md に
  「後ろに物・人がないか確認」安全表示を追加する旨を記載。
- **Important（cos 値・優先順位）**: 0.23.5。`forwardCos=0.75`/`dirCos=0.80`(暫定・`forwardCos<dirCos`)、
  優先順位固定（前方先、ただし hiddenChargeGate 達成時のみ hidden を forward より優先）、`n̂` 正規化不能なら待機/noImpact。
- **Important（idle 低運動量定義）**: 0.23.6。完全停止でなく低運動量 window（netDistance・speed peak が閾値以下）、
  `HakkeiReady` 限定、`validForScore=false` continue は input unavailable 扱い。
- **Implementation Guidance（score/trigger 分離）**: 0.23.7 に `OutcomeTrigger`/`Outcome` 型を明記。
  `calculateScore()` は純計算、`resolveOutcome(trigger, score, config)` が動画・表示可否を決定。score は捨てず保持。
- **検出器の扱い**: 0.23.9。通常 path は `HakkeiDetector + hand selector` に戻し、`DualHakkeiDetector` は Phase B
  special/dev 診断用に温存（「両手でないと出ない」誤実装の再混入防止）。v3 packet 注意（v2 維持・skeleton optional・
  Renderer で score 値を作らない・Gate 分け）も記載。
- **config 追加**: 0.23.10 に `idleEventMs`/`hakkeiReadyTimeoutMs`制約/`forwardCos`/`dirCos`/`idleMaxNetDistance`/
  `idleMaxSpeed`/`hiddenChargeGate`/`dominantHandMargin`、outcome map、appConfig バリデーションを追記。
