## 採用した判断（SPEC §14.1/14.2・設計確定2026-06-23）
- 上下/前後チャージ = 右手の移動差分を Calibration の **upVector / forwardVector へ射影し絶対値を積算**（変位積分）。
  M3 暫定の `max|velocity|`（ピーク速度）を置換。
- フェーズ最初の valid sample は **baseline**（積算しない）。フェーズ変化で baseline リセット（前フェーズ末尾差分を混ぜない）。
- **`verticalNoiseThreshold` / `forwardNoiseThreshold`（デッドゾーン）** を `score.config.normalization` に追加（静止で増えない）。
- **`validForScore=true` の sample だけ積算**（V-1/P0-11 を維持。invalid は baseline も汚さない）。
- 射影に使う位置は filtered `handPosition`（Main 生成。Renderer は再計算しない＝AGENTS §6 準拠）。
- velocity/加速度は Main 生成値を読むだけ。HakkeiReady のピーク収集は当面ピークベース（複合 windowed は M11-06〜）。
