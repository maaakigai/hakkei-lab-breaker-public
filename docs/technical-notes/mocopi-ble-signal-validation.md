# mocopi BLE信号の実機検証

## 結論

mocopi 1台をBLEで直接読み取り、単手パンチ入力として利用できることを実機で確認しました。パンチの勢いを扱う入力には、未同定の加速度フィールドではなく、連続するクォータニオンから求めた角速度を採用しています。

## 測定結果

50Hzで取得した静止区間とパンチ区間を比較しました。

| 区間 | 角速度（deg/sample） | 50Hz換算 |
|---|---:|---:|
| 静止 | 平均0.02 / 最大0.04 | 約2°/s |
| パンチ | 平均5〜6.5 / 最大16〜17 | 最大約800°/s |

- 静止時とパンチ時の最大値には約400倍の差がありました。
- 受信レートは50.0Hz、36byte payloadの形式違反は0件でした。
- 60秒の定常受信では最大gap 90ms、200ms超のgap 0件、切断0件でした。
- 強制切断5回ではアプリを停止せず自動復帰し、センサーが利用可能な状態での再接続は約1.0〜1.2秒でした。

## 採用した処理

1. 現在と直前のクォータニオンを正規化する。
2. `2 × acos(|dot(q_current, q_previous)|)`でフレーム間の回転角を求める。
3. 回転角をサンプル間隔で割り、角速度へ変換する。
4. ウィンドウ内のpeak角速度をパンチ強度、角速度の時間積分をチャージ量として扱う。

角速度は物理的な打撃力や手の直線速度そのものではありません。本作品では、身体動作の勢いをゲーム入力へ安定して変換するための指標として使用しています。
