# Lab Background Images

現行ゲームで使う研究室背景画像の置き場です。

## 現行素材

- `lab-main-front-16x9-privacy.png`: Lv0と破壊映像再生前に表示する、
  公開用に情報部分を除去した16:9の研究室背景画像

Lv1〜Lv5で実際に再生する映像は `assets/videos/LV1/`〜`LV5/` に置き、レベル割り当ては `config/score.config.json` を一次資料とします。未使用の比較候補は公開版に含めません。

## 出典と公開許諾

`lab-main-front-16x9-privacy.png`は、共同制作者が撮影した4:3の研究室写真を
ゲーム背景用に16:9へ加工し、公開用のプライバシー編集を加えたものです。撮影者から、
ゲーム内利用、Wan I2Vへの入力、生成映像を含むGitHubでの一般公開、採用応募資料での
利用について同意を得ています。2026年7月25日にOpenAIの画像生成サービスを用いて、
白板、掲示、紙面などの情報部分を除去しました。Codexが生成候補を比較し、応募者で
ある共同制作者が採用結果と1280×720への縮小を確認・承認しました。無加工の16:9画像
と元の4:3写真は非公開で保管し、このリポジトリには含めていません。
この記録は撮影者・共同制作者の同意範囲を示すもので、施設管理者による別個の書面許可
があるとは表明しません。

同じ4:3写真は、`assets/videos/LV1/`〜`LV5/`の現行プレイ用18本を
`Wan-AI/Wan2.2-I2V-A14B`で生成する際の入力にも使用しました。全18本を無音で
再エンコードし、全フレームへ強い全画面プライバシーぼかし
（`gblur=sigma=20:steps=4`）を適用しました。未使用の比較候補2本は公開版から
除外しています。
`lv5_total_destruction.mp4`はWan生成物ではなく、旧開発用の単色プレースホルダーです。

## 公開時の確認

画像を追加・置換するときは、人物の顔、個人名、読める画面・書類、未公開情報が含まれていないか確認します。研究室備品を識別するために写り込む第三者ブランド名や偶発的なロゴの扱いは、リポジトリ直下の `ASSET_LICENSES.md` に記載しています。
