# Lab Background Images

現行ゲームで使う研究室背景画像の置き場です。

## 現行素材

- `lab-main-front-16x9.png`: Lv0と破壊映像再生前に表示する、
  元の研究室写真を16:9・1280×720へ合わせた正規背景画像

Lv1〜Lv5で実際に再生する映像は `assets/videos/LV1/`〜`LV5/` に置き、レベル割り当ては `config/score.config.json` を一次資料とします。未使用の比較候補は公開版に含めません。

## 出典と公開許諾

`lab-main-front-16x9.png`は、共同制作者が撮影した元の4:3研究室写真を
ゲーム背景用に16:9・1280×720へ合わせたものです。撮影者から、ゲーム内利用、
Wan I2Vへの入力、生成映像を含むGitHubでの一般公開、採用応募資料での利用について
同意を得ています。元の4:3ファイルは非公開で保管し、このリポジトリには同じ写真を
ゲーム表示用に整えた上記16:9背景を収録しています。
この記録は撮影者・共同制作者の同意範囲を示すもので、施設管理者による別個の書面許可
があるとは表明しません。

同じ4:3写真は、`assets/videos/LV1/`〜`LV5/`の現行プレイ用18本を
`Wan-AI/Wan2.2-I2V-A14B`で生成する際の入力にも使用しました。attack114514が
生成操作、プロンプト、シード値の設定を主に担当し、出力の採用・棄却は人間2名が
共同で判断しました。公開中の18本は非公開保全アーカイブ`6ba`から復元した
1280×720のencodeで、音声トラックとぼかし処理はありません。未使用の比較候補2本は
公開版から除外しています。
`lv5_total_destruction.mp4`はWan生成物ではなく、旧開発用の単色プレースホルダーです。

## 公開時の確認

画像を追加・置換するときは、人物の顔、個人名、読める画面・書類、未公開情報が含まれていないか確認します。研究室備品を識別するために写り込む第三者ブランド名や偶発的なロゴの扱いは、リポジトリ直下の `ASSET_LICENSES.md` に記載しています。
